Two people, one task,
one clock.

STRUM records both members of a working pair at once. Two participants run a cooperative urban-reconnaissance mission while a full sensor suite captures each of them — dual high-density EEG, EMG, eye tracking, motion, force and the complete task event timeline — all on a single Lab Streaming Layer clock.

Why a pair

Most recordings of cognitive workload capture one brain at a time. STRUM captures two, doing the work together, on a shared clock — so the questions it can answer are about the pair: how coupling changes during joint action, how load is split between teammates, and how cooperative phases differ from role-split ones within the same session.

The task helps. Every session ran the same five blocks and the same 25 missions, in the same order — not by convention but by construction, since the schedule is generated from a fixed seed in the experiment software. Blocks, missions and rest periods are therefore directly comparable across all 33 pairs, and the inter-block lulls give a rest baseline that costs no extra recording time.

Status

The dataset is complete and BIDS-valid (0 errors, @bids/validator 3.0.1). Public release on OpenNeuro / NEMAR is in preparation, and a data paper is in progress. This page will link the dataset and its DOI as soon as they exist.

Until then, cite the original paper:

T. Mullen, C. Kothe & S. Makeig. STRUM: A New Dataset for Neuroergonomics Research. 2018 IEEE International Conference on Systems, Man, and Cybernetics (SMC), 77–82. doi:10.1109/SMC.2018.00023
